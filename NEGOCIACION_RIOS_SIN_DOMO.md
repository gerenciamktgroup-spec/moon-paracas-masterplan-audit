# 📑 Escenarios de Negociación: Venta de Lote de $2,000\text{ m}^2$ sin Domo (Sr. Ríos)
> **Objetivo:** Definir el precio de venta mínimo y óptimo para un terreno de $2,000\text{ m}^2$ en Paracas Dome sin incluir el domo geodésico ni su kit solar, aprovechando la liquidez inmediata de S/ 20,000 ofrecida por el cliente para iniciar los trámites y papeles del proyecto.

---

## 1. 🛠️ Estructura de Costos del Desarrollador (Costo Directo)

Para saber cuál es nuestro precio mínimo (punto de equilibrio), primero calculamos cuánto nos cuesta a nosotros (desarrolladora) entregar el lote sin domo:

* **Costo de Adquisición de la Tierra:** $\text{S/ } 3.00 / \text{m}^2 \times 2,000\text{ m}^2 = \mathbf{\text{S/ } 6,000.00}$
* **Costo de Habilitación Básica (Caminos afirmados, delimitación de linderos, topografía):** $\text{S/ } 2,500.00$
* **Gasto Administrativo / Legal (Papeles del proyecto, trámites de subdivisión):** $\text{S/ } 1,500.00$
* **COSTO TOTAL DIRECTO DE ENTREGA (Suelo Habilitado):** $\mathbf{\text{S/ } 10,000.00}$

---

## 💵 2. Tres Escenarios de Precio de Venta (Estrategia Comercial)

Dado que el Sr. Ríos ofrece **S/ 20,000.00** como adelanto o préstamo para financiar la "Fase 0" (los trámites iniciales), el desarrollador tiene liquidez garantizada que cubre el $100\%$ de sus costos directos ($\text{S/ } 10,000$) y deja un excedente de caja inmediato de $\text{S/ } 10,000$ para otros gastos operativos del condominio.

Dependiendo de qué tan atractiva queramos hacer la oferta, podemos proponer estos 3 escenarios:

### Escenario A: "Socio Fundador / Trueque de Liquidez" (Precio S/ 20,000 - Contado)
* **Precio de Venta:** **S/ 20,000.00** (Equivale a un precio de remate de **$\text{S/ } 10.00 / \text{m}^2$**).
* **Forma de Pago:** $\text{S/ } 20,000$ cancelado al contado hoy.
* **Estructura Financiera:** El cliente paga el lote completo con su aporte inicial.
* **Ventaja Desarrolladora:** Margen neto del $100\%$ sobre el costo directo ($\text{S/ } 10,000$ de ganancia neta). Recibimos caja inmediata en Fase 0 sin tener que cobrar cuotas a futuro.
* **Ventaja Cliente:** Compra a un precio bajísimo (un tercio del precio de lista con domo).

### Escenario B: "Preventa Especial sin Domo" (Precio S/ 25,000 - Con Saldo)
* **Precio de Venta:** **S/ 25,000.00** (Equivale a **$\text{S/ } 12.50 / \text{m}^2$**).
* **Forma de Pago:** 
  * *Inicial (Adelanto Hoy):* $\text{S/ } 20,000$ ($80\%$ del total).
  * *Saldo contra entrega de lote:* $\text{S/ } 5,000$ (sin intereses, a la entrega de la posesión física y planos).
* **Estructura Financiera:** Genera una cuenta por cobrar que reduce el riesgo del cliente y asegura la entrega final.
* **Ventaja Desarrolladora:** Margen de ganancia de **$\text{S/ } 15,000.00$** ($150\%$ de rentabilidad sobre costo).
* **Ventaja Cliente:** Asegura un excelente precio y retiene un saldo final como garantía de la entrega física del terreno.

### Escenario C: "Precio de Lista sin Domo / Financiamiento" (Precio S/ 35,000 - Estándar)
Si restamos el valor estimado de fabricación, equipamiento solar e instalación de un domo premium de 8m ($\sim\text{S/ } 25,000$) al precio de lista de $\text{S/ } 60,000$, el valor comercial de lista de la tierra sola es de **S/ 35,000**.
* **Precio de Venta:** **S/ 35,000.00** (Equivale a **$\text{S/ } 17.50 / \text{m}^2$**).
* **Forma de Pago:**
  * *Inicial (Hoy):* $\text{S/ } 20,000$ ($57.1\%$ del total).
  * *Saldo Financiado:* $\text{S/ } 15,000$ (+ $5\%$ interés flat = $\text{S/ } 15,750$).
  * *Cuotas:* 12 mensualidades de **$\text{S/ } 1,312.50$ / mes**.
* **Ventaja Desarrolladora:** Maximiza el beneficio económico con una utilidad neta de **$\text{S/ } 25,000.00$** ($250\%$ de rentabilidad sobre costo).
* **Ventaja Cliente:** Entra al proyecto con las condiciones comerciales estándar de lista pero sin la obligación de construir el domo, pudiendo autoconstruir a su propio ritmo.

---

## 🎯 Recomendación Comercial para la Desarrolladora

Para incentivar la inyección rápida de capital sin sacrificar demasiado margen a futuro, la mejor opción a plantear al Sr. Ríos es el **Escenario B (S/ 25,000.00)**. 

Le permites ingresar con sus **S/ 20,000** como cuota inicial mayoritaria (lo cual te da la caja necesaria para arrancar los papeles e ingeniería del proyecto inmediatamente), y dejas un saldo de **S/ 5,000** para el momento de la entrega del lote, lo cual le genera confianza al cliente de que el desarrollador cumplirá con la habilitación del terreno.
