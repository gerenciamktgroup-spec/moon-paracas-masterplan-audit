========================================
MOON PARACAS - MEJORAS 3D PARA LA WEB
========================================

## CONTEXTO DEL PROYECTO
Moon Paracas es un condominio ecológico de lujo silencioso en Paracas, Perú. 
- Área Total: 112,391.80 m² (11.2 hectáreas)
- Total Lotes: 312 lotes residenciales + 138 cocheras = 450 elementos
- Tipologías: 5 tipos (Premium/Oasis, Zen, Estándar, Tiny House, Ajuste)
- Ubicación: Tablazo elevado a 110 msnm (sin riesgo de tsunami)
- Coordenadas UTM: 374550-375075 Este, Zona 18S

## OBJETIVOS DE LAS MEJORAS 3D
1. Mejorar la experiencia del usuario con visualizaciones inmersivas
2. Mostrar la geometría real del masterplan (no un rombo genérico)
3. Permitir a los clientes visualizar su futuro lote en contexto
4. Aumentar la confianza mediante representaciones reales y precisas
5. Diferenciarnos de competidores con tecnología innovadora

## MEJORAS 3D ESPECÍFICAS

### 1. PLANO 3D INTERACTIVO DEL MASTERPLAN (Con Three.js)
- Modelo 3D del masterplan con geometría real basado en el CAD
- Navegación intuitiva: Rotar, acercar, moverse en el plano
- Filtros 3D: Activar/desactivar manzanas, tipos de lotes, estados
- Detalle por lote: Al hacer clic en un lote, se muestra información detallada
- Fases de construcción: Visualización progresiva del proyecto

### 2. RECORRIDOS VIRTUALES 360° (Con A-Frame)
- 3 recorridos virtuales:
  1. Recorrido Diurno: Experiencia del "lujo silencioso" en el desierto
  2. Recorrido Nocturno: Mostrar el "sendero bioluminiscente" y el mirador astronómico
  3. Recorrido de Tipologías: Mostrar las 5 tipologías de vivienda en contexto

### 3. VISUALIZACIÓN ARQUITECTÓNICA 3D INTERACTIVA
- Modelos 3D de cada tipología de vivienda
- Personalización en tiempo real: Cambiar colores, materiales, xeripaisajismo
- Comparación entre tipologías: Mostrar las 5 tipologías lado a lado

### 4. SIMULADOR 3D DE SOSTENIBILIDAD
- Simulación de energía solar: Generación de energía a lo largo del día
- Simulación de ventilación: Visualizar cómo funciona la ventilación cruzada
- Simulación de agua: Flujo de agua desde la cisterna hasta las viviendas

### 5. REALIDAD AUMENTADA PARA MÓVILES
- AR para móviles: Visualizar el lote en el contexto real
- AR para cocheras: Ubicación exacta de las cocheras
- AR para el helipuerto: Integración en el paisaje

### 6. INTEGRACIÓN DE HERRAMIENTAS DE DISEÑO 3D (Con Spline)
- Integrar Spline para permitir a los clientes diseñar su propia vivienda
- Plantilla 3D de cada tipología que los clientes puedan personalizar
- Exportar diseño para validación por el equipo de construcción

## INSTRUCCIONES TÉCNICAS PARA ANTIGRAVITY

### PASO 1: PREPARACIÓN DE LOS DATOS
1. **Cargar datos reales del proyecto**:
   - Usar INVENTARIO_MOON_PARACAS.csv para los 450 elementos (312 lotes + 138 cocheras)
   - Parsear CSV a JSON con estructura:
     ```json
     {
       "id": "L001",
       "manzana": "M1",
       "tipologia": "Lote Estándar",
       "area_m2": 225.54,
       "estado": "disponible",
       "coordenadas": { "x": 374550.00, "y": 8460135.00 }
     }
     ```
   - Generar geometría 3D real basada en las coordenadas UTM

2. **Implementar sistema de estados**:
   - Colores según estado:
     - Disponible: verde (#4caf50)
     - En Oferta: rosa (#e91e63)
     - Separado: naranja (#ff9800)
     - Vendido: rojo (#f44336)

### PASO 2: IMPLEMENTACIÓN DE MEJORAS 3D

#### 1. PLANO 3D INTERACTIVO (Three.js)
```javascript
// THREE.JS - Masterplan 3D
import * as THREE from 'three';
import { OrbitControls } from 'three/examples/jsm/controls/OrbitControls';
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader';

// Configuración básica
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
const renderer = new THREE.WebGLRenderer({ antialias: true, alpha: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setPixelRatio(window.devicePixelRatio);
document.getElementById('3d-masterplan').appendChild(renderer.domElement);

// Cargar modelo 3D del masterplan
const loader = new THREE.GLTFLoader();
loader.load('models/masterplan.gltf', function(gltf) {
  scene.add(gltf.scene);
  
  // Aplicar filtros de estado
  gltf.scene.traverse(function(object) {
    if (object.isMesh) {
      // Colores según estado
      if (object.userData.estado === 'disponible') {
        object.material.color.set(0x4caf50);
      } else if (object.userData.estado === 'en_oferta') {
        object.material.color.set(0xe91e63);
      } else if (object.userData.estado === 'separado') {
        object.material.color.set(0xff9800);
      } else if (object.userData.estado === 'vendido') {
        object.material.color.set(0xf44336);
      }
    }
  });
});

// Configurar controles
const controls = new OrbitControls(camera, renderer.domElement);
camera.position.set(0, 200, 500);
controls.update();

// Manejar clic en lotes
renderer.domElement.addEventListener('click', function(event) {
  // Lógica para identificar el lote clickeado
  // Mostrar información en el panel
  const mouse = new THREE.Vector2();
  mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
  mouse.y = -(event.clientY / window.innerHeight) * 2 + 1;
  
  const raycaster = new THREE.Raycaster();
  raycaster.setFromCamera(mouse, camera);
  
  const intersects = raycaster.intersectObjects(scene.children);
  if (intersects.length > 0) {
    const selectedObject = intersects[0].object;
    // Mostrar información del lote seleccionado
    showLoteInfo(selectedObject.userData);
  }
});

// Manejar redimensionamiento
window.addEventListener('resize', function() {
  camera.aspect = window.innerWidth / window.innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(window.innerWidth, window.innerHeight);
});

// Animación
function animate() {
  requestAnimationFrame(animate);
  controls.update();
  renderer.render(scene, camera);
}
animate();

// Función para mostrar información del lote
function showLoteInfo(loteData) {
  document.getElementById('lote-info').innerHTML = `
    <h3>${loteData.id}</h3>
    <p><strong>Manzana:</strong> ${loteData.manzana}</p>
    <p><strong>Tipología:</strong> ${loteData.tipologia}</p>
    <p><strong>Área:</strong> ${loteData.area_m2} m²</p>
    <p><strong>Estado:</strong> ${loteData.estado.toUpperCase()}</p>
    <p><strong>Precio:</strong> S/ ${loteData.precio}</p>
    <button class="btn-primary" onclick="reserveLote('${loteData.id}')">Reservar Lote</button>
  `;
}
