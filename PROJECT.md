# Project: Moon Paracas Re-engineering

## Architecture
The application is a React + Vite + TypeScript frontend that visualizes the Moon Paracas masterplan map (lots, roads, amenities, parking hubs) using SVG rendering on a custom MapCanvas. 
- **Data Flow**:
  - `src/lib/terrainModel.ts` generates the terrain dimensions and boundaries.
  - `src/lib/blockModel.ts` generates block boundaries, curved bands, and the central Oasis.
  - `src/lib/roadModel.ts` and `src/lib/geometry.ts` generate and offset road shapes.
  - `src/lib/lotModel.ts` generates residential lots and parking spots within the blocks/hubs.
  - `seed_db.ts` triggers layout generation and seeds Firestore database with lot data and metadata.
  - The frontend maps this data via Firebase config to display available, sold, and details of lots on a React canvas.
- **Interfaces**:
  - `Lot` interface in `src/types/map.d.ts` (or equivalent types file) defines the schema for lots.
  - Business rules in `src/data/business.ts` govern block/lot generation counts and constraints.

## Interface Contracts
### `Lot` Metadata Schema
The lot objects generated by `lotModel.ts` and uploaded to Firestore must include:
- `frontage: number` (strictly 10.0m - 12.0m for residential)
- `depth: number` (average depth in meters)
- `price_soles: number` (price calculated based on area)
- `parking_type: "externo_ingreso" | "periferico_interno"` (assigned parking type)
- `walk_distance_parking_meters: number` (strictly < 150m for all residential lots)
- `walk_distance_oasis_meters: number` (distance to Oasis boundary)

## Code Layout
- `src/data/business.ts` — contains `BLOCK_SPECS` and target lot configurations.
- `src/lib/blockModel.ts` — defines curved blocks and oasis boundaries.
- `src/lib/lotModel.ts` — splits blocks into curved lot subdivisions and lays out parking hubs.
- `src/components/map/MapCanvas.tsx` — handles interactive lot rendering.
- `src/components/LotDetailsModal.tsx` — displays specific modal details for a clicked lot.
- `seed_db.ts` — seeds Firestore database.
- `test_layout_v3.ts` — local geometric layout validation script.
